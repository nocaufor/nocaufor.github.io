## 3. 使用方式

首页通过 `<model-viewer>` 引用（`assets/js/home-new.js` 的 `initModel()` 以模板实例化）：

```
src="assets/models/nocau-orbits/nocau-orbits.gltf"
environment-image="neutral"
```

首屏下方图标区（`tk-badge-tpl` 模板）复用同一 glTF，绝对定位与 CSS 轨道图标同位同尺度，
加载完成后容器加 `is-3d`、隐藏原 CSS 图标。

渲染参数（随主题联动）：

- 浅色主题：`exposure 1.12`、`shadow-intensity 1.05`、`shadow-softness 1`、`tone-mapping neutral`
- 深色主题：`exposure 1`、`shadow-intensity 1.3`、`shadow-softness 0.9`、`tone-mapping neutral`
- 低端设备（CPU ≤ 4 核或内存 ≤ 4G）：关闭自动旋转与相机交互，`shadow-intensity 0.6`、`exposure 1`
