FAQ

常见问题

也许你想问的已经有了答案。

可以承接什么类型的项目？

主要承接微信小程序、Android 应用、AI 工具平台前端以及静态站点的设计与开发。偏好小而清晰的工具类产品，复杂业务可以讨论拆分。

合作周期大概多久？

简单的工具类小程序约 2-4 周，中大型平台项目 1-3 个月不等。关键在需求边界是否清晰，沟通越充分，交付越快。

是否支持远程协作？

支持。日常通过微信 / 邮箱沟通，每周固定演示进度，关键节点可视频会议对齐，交付物全部线上共享。

源码和知识产权归谁？

定制项目按合同约定，默认源码与知识产权归委托方；开源项目按对应开源许可（如 MIT）执行，允许任何人查看与使用。

这个作品集站点是纯静态的吗？

是的。全站纯 HTML / CSS / JS，零构建、零后端、零依赖，部署在 GitHub Pages，CSP 安全头与相对路径保证任意子路径可部署。
