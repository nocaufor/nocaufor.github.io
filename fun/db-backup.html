数据库备份与归档轮转

mysqldump / 文件归档 + 定时备份 + 保留策略轮转，脚本化运维。

场景：运维自动化 技术栈：Python 来源：GitHub 参考

项目简介

备份永远在“需要的那一刻”才显得重要。本页提供一套备份与轮转脚本：定时导出 MySQL 数据库或归档目录，按天保留最近 N 份、按月保留归档，自动清理过期文件；配合系统定时任务即可无人值守。

代码示例：备份与轮转

py
import os
import shutil
import subprocess
from pathlib import Path
from datetime import datetime

BACKUP_ROOT = Path("/var/backups/mysql")
KEEP_DAILY = 7      # 保留最近 7 天
KEEP_MONTHLY = 12   # 每月保留 12 个月

def dump_mysql(db: str, user: str, password: str) -> Path:
    stamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    out = BACKUP_ROOT / f"{db}_{stamp}.sql.gz"
    cmd = [
        "mysqldump", f"-u{user}", f"-p{password}",
        "--single-transaction", "--quick", db,
    ]
    with out.open("wb") as f:
        subprocess.run(cmd, stdout=f, check=True)
    return out

def rotate(root: Path, keep_daily: int, keep_monthly: int) -> list[Path]:
    files = sorted(root.glob("*.sql.gz"))
    removed: list[Path] = []
    for f in files[:-keep_daily]:          # 超过日保留数
        if f.name[9:15] == "01":           # 每月 1 号备份：改按月保留
            month_dir = root / "monthly"
            month_dir.mkdir(exist_ok=True)
            shutil.move(str(f), str(month_dir / f.name))
            continue
        f.unlink()
        removed.append(f)
    for f in sorted((root / "monthly").glob("*.sql.gz"))[:-keep_monthly]:
        f.unlink()
        removed.append(f)
    return removed

if __name__ == "__main__":
    os.environ.setdefault("DB_PASS", "")
    dump_mysql("app", "root", os.environ["DB_PASS"])
    for f in rotate(BACKUP_ROOT, KEEP_DAILY, KEEP_MONTHLY):
        print("removed", f)

代码示例：Windows 任务计划注册（PowerShell）

ps1
# 每天 02:30 执行备份脚本
$action  = New-ScheduledTaskAction -Execute "python" -Argument "C:\scripts\db_backup.py"
$trigger = New-ScheduledTaskTrigger -Daily -At 02:30
Register-ScheduledTask -TaskName "nocau-db-backup" `
  -Action $action -Trigger $trigger -Force

操作步骤

  1. 把 dump_mysql 的库名、用户名改为实际值，密码通过环境变量 DB_PASS 注入。
  2. 首次手动运行验证备份文件可正常恢复（gunzip < file.sql.gz | mysql -u root db）。
  3. 注册系统定时任务每日执行；Linux 场景改用 crontab。
