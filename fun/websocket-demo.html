WebSocket 实时通信最小实现

浏览器 + Node ws 的实时聊天 / 推送最小闭环，含心跳与重连。

场景：实时通信 技术栈：Node.js / WebSocket 来源：GitHub 参考

项目简介

聊天、协作白板、实时推送，底层大多是 WebSocket。本页给出最小可运行闭环：Node 端用 ws 库维护连接并广播消息，浏览器端封装了心跳保活与断线自动重连，覆盖实时应用最常见的工程要点。

代码示例：Node 服务端

js
const { WebSocketServer } = require("ws");

const wss = new WebSocketServer({ port: 8080 });
const clients = new Set();

wss.on("connection", (ws) => {
  clients.add(ws);
  ws.isAlive = true;
  ws.on("pong", () => { ws.isAlive = true; });
  ws.on("message", (raw) => {
    // 广播给所有客户端（生产环境应加身份与房间过滤）
    for (const c of clients) {
      if (c.readyState === 1) c.send(raw.toString());
    }
  });
  ws.on("close", () => clients.delete(ws));
});

// 心跳：每 30s 检测，未 pong 的连接直接终止
setInterval(() => {
  for (const ws of clients) {
    if (!ws.isAlive) { ws.terminate(); clients.delete(ws); continue; }
    ws.isAlive = false;
    ws.ping();
  }
}, 30000);

代码示例：浏览器端封装（含重连）

js
function createSocket(url, { onMessage, onStatus }) {
  let ws = null;
  let retry = 0;
  let beat = null;

  function connect() {
    ws = new WebSocket(url);
    ws.onopen = () => {
      retry = 0;
      onStatus && onStatus("online");
      beat = setInterval(() => ws.readyState === 1 && ws.send("ping"), 25000);
    };
    ws.onmessage = (e) => onMessage && onMessage(e.data);
    ws.onclose = () => {
      clearInterval(beat);
      onStatus && onStatus("offline");
      // 指数退避重连：1s, 2s, 4s ... 上限 15s
      const delay = Math.min(1000 * 2 ** retry, 15000);
      retry += 1;
      setTimeout(connect, delay);
    };
    ws.onerror = () => ws.close();
  }
  connect();
  return {
    send: (data) => ws && ws.readyState === 1 && ws.send(data),
    close: () => { clearInterval(beat); ws.close(); }
  };
}

操作步骤

  1. 服务端 npm i ws 后运行 node server.js，监听 8080 端口。
  2. 浏览器端打开页面即可连接：输入消息点击发送，其他页面实时收到广播。
  3. 断网后客户端按指数退避自动重连；服务端心跳 30s 清理僵尸连接。
