图像批量压缩与水印

Pillow 批量缩放、压缩质量与添加文字 / 图片水印，节省存储空间。

场景：图片处理 技术栈：Python / Pillow 来源：GitHub 参考

项目简介

产品图、公众号配图、摄影原片，批量处理是刚需。本页用 Pillow 实现批量压缩与水印：统一缩放最大边、按质量压缩 JPEG / WebP、叠加文字水印或 Logo，最后统计节省空间比例，适合接入图片上传流水线。

代码示例：批量压缩与水印

py
from pathlib import Path
from PIL import Image, ImageDraw, ImageFont

MAX_EDGE = 1600
QUALITY = 82
WATERMARK_TEXT = "nocau.com"

def process_one(src: Path, out_dir: Path) -> int:
    img = Image.open(src)
    img = img.convert("RGB")
    # 等比缩放：最长边不超过 MAX_EDGE
    if max(img.size) > MAX_EDGE:
        img.thumbnail((MAX_EDGE, MAX_EDGE), Image.LANCZOS)
    # 右下角文字水印（可换为 Image.paste 贴 Logo）
    draw = ImageDraw.Draw(img)
    font = ImageFont.truetype("arial.ttf", 28)
    w, h = draw.textbbox((0, 0), WATERMARK_TEXT, font=font)[2:]
    px, py = img.width - w - 18, img.height - h - 18
    draw.rectangle([px - 8, py - 6, px + w + 8, py + h + 6], fill=(0, 0, 0, 160))
    draw.text((px, py), WATERMARK_TEXT, fill=(255, 255, 255), font=font)
    # 输出 JPEG 质量压缩
    out = out_dir / (src.stem + "_wm.jpg")
    img.save(out, "JPEG", quality=QUALITY, optimize=True)
    return src.stat().st_size - out.stat().st_size

def batch(root: Path, out_root: Path) -> None:
    out_root.mkdir(parents=True, exist_ok=True)
    saved = 0
    for p in root.glob("*.{jpg,jpeg,png,webp}"):
        saved += process_one(p, out_root)
    print(f"saved {saved / 1024 / 1024:.1f} MB")

操作步骤

  1. pip install Pillow 后运行 python image_batch.py 输入目录 输出目录。
  2. 调整 MAX_EDGE / QUALITY 权衡体积与画质；透明 PNG 建议输出 WebP 保留 alpha。
  3. 水印文字可替换为 Logo 图片：img.paste(logo, (px, py), logo)。
