通用单位换算器

长度、重量、温度、数据量等常见单位互转，离线可用、实时更新。

场景：效率工具 技术栈：HTML / JS 来源：GitHub 参考

项目简介

日常开发与写作里最常见的需求之一：把 16 寸换算成厘米、把 1.5TB 换算成 GB。本页给出一个因子表驱动的单位换算器：每种物理量维护一张换算因子表，输入数值即可在任意单位间实时换算，逻辑清晰、易于扩展。

代码示例：因子表驱动换算

js
const CATEGORIES = {
  length: { base: "m",
    units: { mm: 0.001, cm: 0.01, m: 1, km: 1000,
             inch: 0.0254, ft: 0.3048, yd: 0.9144, mi: 1609.344 } },
  weight: { base: "kg",
    units: { mg: 1e-6, g: 0.001, kg: 1, t: 1000,
             oz: 0.028349523, lb: 0.45359237 } },
  data: { base: "byte",
    units: { b: 1, kb: 1024, mb: 1024 ** 2, gb: 1024 ** 3,
             tb: 1024 ** 4, pb: 1024 ** 5 } }
};

function convert(category, value, from, to) {
  const { units } = CATEGORIES[category];
  if (!(from in units) || !(to in units)) return null;
  return value * units[from] / units[to]; // 统一先换算到基准单位
}

function format(n) {
  if (!isFinite(n)) return "∞";
  return Math.abs(n) >= 10000 || (Math.abs(n) < 0.001 && n !== 0)
    ? n.toExponential(4)
    : String(parseFloat(n.toFixed(6)));
}

代码示例：温度换算（非均匀公式）

js
// 温度换算不是线性因子，单独处理
const TEMP = {
  c: { f: v => v * 9 / 5 + 32, k: v => v + 273.15 },
  f: { c: v => (v - 32) * 5 / 9, k: v => (v - 32) * 5 / 9 + 273.15 },
  k: { c: v => v - 273.15, f: v => (v - 273.15) * 9 / 5 + 32 }
};
function convertTemp(value, from, to) {
  if (from === to) return value;
  return TEMP[from][to](value);
}

操作步骤

  1. 选择物理量（长度 / 重量 / 数据量 / 温度），输入数值并选择源单位与目标单位。
  2. 结果实时更新：线性量走因子表统一换算，温度走公式分支。
  3. 新增单位只需在 units 表里加一行因子，无需改动换算逻辑。
